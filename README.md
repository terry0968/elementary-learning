# Elementary 小學練習樂園

給國小一年級孩子使用的學習遊戲樂園，從國語、數學與英文課程地圖進入逐課教學與小測，包含注音輔助、課程解鎖、本機進度保存，以及數學加碼挑戰。

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用任何靜態網站伺服器預覽。

## 發布到 GitHub Pages

1. 將本資料夾內容推送到 GitHub repository 的 `main` 分支。
2. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 將來源設為 `main` 分支的 `/ (root)` 資料夾並儲存。
4. 等待 GitHub Pages 部署完成後，即可使用 repository 專屬網址瀏覽網站。

課程內容為原創入門練習，依一年級常見學習方向編寫，並非任何出版社課本的逐課內容。
