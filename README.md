# Elementary 小學練習樂園

給國小一年級孩子使用的學習遊戲樂園，從國語、數學與英文課程地圖進入逐課教學與小測，包含注音輔助、題目語音朗讀、課程解鎖與本機進度保存。

國語課程依翰林一上首冊注音教學、第一冊課文與統整活動編排，共 20 課；數學依南一一上九個單元編排，每單元小測 10 題。英文維持 6 課，每課小測 3 題。

題目朗讀優先使用裝置提供的繁體中文（台灣）語音；語音清單尚未載入時，會以 `zh-TW` 語系嘗試朗讀，不會明確選用中國大陸語音。

練習題為依課程範圍編寫的原創題目，並非照錄課本題目。課程目錄參考以下 115 學年度公開教學計畫：

- [屏東縣國語文教學計畫（一年級，翰林）](https://www.cp.ptc.edu.tw/storage/134633/134633_115_B-01_1A.pdf)
- [屏東縣數學教學計畫（一年級，南一）](https://www.cp.ptc.edu.tw/storage/134657/134657_115_B-04_1A.pdf)

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用任何靜態網站伺服器預覽。

## 發布到 GitHub Pages

1. 將本資料夾內容推送到 GitHub repository 的 `main` 分支。
2. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**。
3. 將來源設為 `main` 分支的 `/ (root)` 資料夾並儲存。
4. 等待 GitHub Pages 部署完成後，即可使用 repository 專屬網址瀏覽網站。

英文練習依一年級常見學習方向編寫；國語與數學則按上述課程計畫的課次／單元順序設計。
